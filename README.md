# Neighbors Pest Solutions

Marketing website for Neighbors Pest Solutions, built with Next.js and deployed
on Vercel.

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy `.env.example` to
`.env.local` and fill in the services used locally.

## Internal attribution reporting

The repository includes a hidden, Google-authenticated FieldRoutes attribution
dashboard with a once-daily private data snapshot. See
[`docs/attribution-dashboard.md`](docs/attribution-dashboard.md) for setup,
security boundaries, sync behavior, and reporting definitions.
